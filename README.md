# MFC Power Density Prediction using Machine Learning

A proof-of-concept machine learning pipeline that predicts the power density of Microbial Fuel Cells (MFCs) from design and operating parameters. This repository accompanies a review paper section on data-driven optimization of bioelectrochemical systems.

---

## Overview

Microbial Fuel Cells convert organic matter directly into electricity using exoelectrogenic bacteria. However, MFC performance is governed by complex, nonlinear interactions among anode/cathode materials, membrane type, substrate composition, pH, temperature, and reactor geometry. Traditional trial-and-error optimization is slow and expensive.

This project demonstrates how supervised machine learning can:
- Predict power density (mW/m²) from easily measurable design parameters
- Identify which factors most strongly influence performance
- Provide a foundation for physics-informed ML in future work

This is a **proof-of-concept**, not a validated predictive tool. It is intended to accompany a review paper and illustrate a data-driven research direction.
